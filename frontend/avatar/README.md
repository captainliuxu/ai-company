# [FUTURE] Avatar / Live2D Module

This directory is reserved for the future digital human avatar system.

## Planned Stack
- Live2D Cubism SDK for Web
- Lip-sync with TTS audio
- Emotion expression mapping
- Idle animations (breathing, blinking)

## Integration Points
- Persona.avatar_url → loads avatar model
- Emotion state → drives facial expression
- Voice TTS → drives lip-sync
