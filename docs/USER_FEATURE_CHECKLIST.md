# 用户功能验收清单

> 记录格式：`[功能编号] [严重程度：Critical/Major/Minor] 描述 + 复现步骤`

## 一、启动与基础

- [ ] 1.1 启动后端：`uvicorn backend.main:app --host 0.0.0.0 --port 8000` 无报错
- [ ] 1.2 访问 `http://localhost:8000/docs` Swagger 页面正常显示
- [ ] 1.3 访问 `http://localhost:8000/health` 返回 `{"status":"healthy"}`
- [ ] 1.4 启动前端：`npm run dev --prefix frontend` 无报错
- [ ] 1.5 访问 `http://localhost:3000` 自动跳转到 `/personas`

## 二、角色选择

- [ ] 2.1 页面显示标题"选择你的AI伴侣"
- [ ] 2.2 显示 3 张角色卡片：小暖、小锐、小默
- [ ] 2.3 每张卡片显示：名字 + 性格描述（如"温柔体贴、善解人意"）+ 说话风格
- [ ] 2.4 加载中显示 spinner 动画
- [ ] 2.5 后端未启动时显示错误提示（不是白屏）

## 三、小暖聊天（温柔型）

- [ ] 3.1 点击"小暖"卡片 → 跳转到 `/chat?persona_id=xxx`
- [ ] 3.2 页面顶部显示"小暖"名字 + "温柔体贴、善解人意"
- [ ] 3.3 无消息时显示"向小暖发送第一条消息吧~"
- [x] 3.4 输入框为空时，发送按钮不可点击（灰色禁用）,并不是纯灰色，你的设置成了原本的橙色再稍微变暗，我需要纯灰色
- [ ] 3.5 输入消息后，发送按钮变为可点击
- [ ] 3.6 点击发送 / 按 Enter → 用户消息以橙色气泡右对齐显示
- [ ] 3.7 等待回复期间显示三点跳动动画（typing indicator）
- [x] 3.8 AI 回复以灰色气泡左对齐逐字显示（SSE 流式）  并不是流式输出，或者你的流式速度太快导致我无法判断
- [ ] 3.9 回复结束后光标消失，输入框重新可用
- [ ] 3.10 回复风格体现小暖温柔体贴性格（如使用"呀"、"小暖"自称、语气软糯）
- [ ] 3.11 多条消息后列表自动滚动到底部
- [ ] 3.12 发送中无法再次点击发送（按钮禁用）
- [ ] 3.13 快速连发两条消息，前一个 SSE 被 abort，不会出现重复回复

## 六、情绪面板

- [ ] 6.1 首次聊天后，聊天页顶部出现情绪四维度面板
- [ ] 6.2 面板显示：粉色好感度数值、蓝色信任度数值、橙色心情文字、紫色依赖度数值
- [ ] 6.3 发送第二、第三条消息后，情绪数值发生变化（不是固定不变的）
- [ ] 6.4 心情文字与对话内容相关（如说"我很累" → 心情可能显示"疲惫"）

## 七、长期记忆

- [ ] 7.1 在聊天中主动提到个人信息（如"我叫张三，喜欢打篮球，住在杭州"）
- [ ] 7.2 发送后等待 AI 回复完成
- [ ] 7.3 用 Swagger 或 curl 访问 `GET /api/v1/memories/{session_id}` 返回记忆列表
- [ ] 7.4 记忆列表中包含刚才提到的信息（如"用户姓名：张三"、"用户偏好：喜欢打篮球"）
- [ ] 7.5 记忆按 type 分类（user_info / preference / event / emotion）
- [ ] 7.6 记忆包含 importance 评分（1-5）
- [ ] 7.7 `GET /api/v1/memories/{session_id}?type=preference` 只返回偏好类记忆
- [ ] 7.8 重启后端后，用同一 session_id 查记忆，数据仍在

## 十一、错误与边界

- [ ] 11.2 访问 `http://localhost:3000/chat?persona_id=invalid` → 显示"角色不存在" + 返回链接
